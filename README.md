# She-Shield

## Women Safety Application

She-Shield is a women safety web application developed using React and Express.js to provide emergency assistance for women. The platform enables users to share their live location, send SOS alerts, trigger automatic emergency emails, and use geotagging for accurate location tracking during critical situations.

### Features

* 🚨 One-Tap SOS Alert System
* 📍 Real-Time Location Tracking
* 📧 Automatic Emergency Email Notifications
* 🌐 Geotagging and Location Sharing
* 👥 Emergency Contact Management
* 🔒 Secure and User-Friendly Interface

### Tech Stack

#### Frontend

* React.js
* HTML5
* CSS3
* JavaScript

#### Backend

* Express.js
* Node.js

### Objective

She-Shield aims to improve women's safety by providing instant emergency communication and real-time location sharing, helping trusted contacts respond quickly when assistance is needed.
